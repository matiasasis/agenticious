UP AND RUNNING

A few steps.
Then, summon.

You’ll need an Apple silicon Mac running macOS 14 or later, plus Claude Code or Codex installed and signed in. Provider accounts and usage are separate from this free app.

  1. Download and move to Applications

    Unzip the download, then drag Agenticious.app into your Applications folder.

  2. Approve the first launch

    Try opening Agenticious once. Because this build has no Apple Developer ID signature or notarization, macOS may block it. If you trust this download, open System Settings → Privacy & Security → Open Anyway, then confirm. Read Apple’s instructions ↗

    On a managed work Mac, your organization may restrict this option. No need to disable Gatekeeper globally.

  3. Choose your workspace and agent

    Make sure your preferred provider’s CLI is available in your login shell. Open Agenticious, choose a project, and describe your first task.
